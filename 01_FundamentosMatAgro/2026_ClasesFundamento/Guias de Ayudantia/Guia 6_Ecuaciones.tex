	\begin{enumerate}
			\item 	Un modelo de aplicación de nitrógeno considera pérdidas por lixiviación:
			
			\[
			0{,}85(12x + 150) - 60 = 900
			\]
		¿Cuántas hectáreas deben ser fertilizadas para que el cultivo reciba exactamente 900 kg de nitrógeno efectivo?
		
		\item En un sistema de riego se modela por la siguiente ecuación:
				
		\[
		\frac{3}{4}(20x + 200) - (5x + 80) = 600
		\]
		
		donde $x$: horas de riego. Determine el tiempo de riego necesario. Analice si el sistema es eficiente.
		
		\item En fertirrigación se combinan dos soluciones:
		
		\[
		\frac{5x + 40}{3} - \frac{2x - 10}{4} = 100
		\]
		
		donde $x$: concentración base (mg/L)
		
		\begin{enumerate}
			\item Elimine denominadores.
			\item Resuelva la ecuación.
			\item Interprete el resultado en términos de concentración.
		\end{enumerate}
		
		\item El ingreso y costo de producción están dados por:
		
		\[
		15x + 200 = 8x + 500
		\]
		
		donde:
		\begin{itemize}
			\item $x$: toneladas producidas
		\end{itemize}
		
		\begin{enumerate}
			\item Determine el punto de equilibrio.
			\item Interprete el resultado económicamente.
		\end{enumerate}
		
		\item Dada la siguiente ecuación:	$V = axt - bx + c$
		
		donde:
		\begin{itemize}
			\item $V$: volumen total (L)
			\item $a$: tasa de aplicación
			\item $b$: pérdidas por infiltración
			\item $c$: volumen inicial
		\end{itemize}
		
		
		Despeje $x$.

		2(5x + 50) - 3x = 10x + 100$

		\begin{enumerate}
			\item Verifique el resultado.
			\item Analice si tiene sentido físico en agronomía.
			\item Corrija si es necesario.
		\end{enumerate}
		
		\item Dada la siguiente ecuación:
		\[
		\frac{2(3x + 60)}{5} + \frac{x - 20}{2} = 150
		\]
		
		\begin{enumerate}
			\item Resuelva la ecuación.
			\item Interprete el resultado como dosis de fertilizante.
			\item Evalúe coherencia del modelo.
		\end{enumerate}
		
		\item Considere la siguiente ecuación:
			\[
		0{,}9(10x + 300) - 0{,}2(5x + 100) = 1000
		\]
		
		\begin{enumerate}
			\item Determine $x$.
			\item Interprete el resultado en consumo energético.
		\end{enumerate}
	
	\item Un modelo agrícola integrado está dado por:
	
	\[
	\frac{3(4x + 120)}{2} - \frac{2(5x - 50)}{3} = 500
	\]
	
	\begin{enumerate}
		\item Resuelva la ecuación.
		\item Interprete el resultado en contexto productivo.
		\item Analice posibles errores de modelación.
	\end{enumerate}
	
	\item Un estudiante de agronomía trabaja como ayudante en un predio agrícola durante la temporada de cosecha. Cada día siguiente recibe $5/4$ del pago del día anterior, debido a una disminución progresiva en las horas trabajadas.
	El total recibido en los tres días es de $\$219\,600$.
	
	\item En un estudio fitosanitario, un equipo de agrónomos evalúa la presencia de una enfermedad fúngica en cultivos de trigo dentro de una zona agrícola.
	
	Se analiza una muestra de \textbf{450 plantas}, de las cuales \textbf{36 presentan síntomas de infección}.
	
	Si la zona total de cultivo contiene aproximadamente \textbf{200.000 plantas}, se desea estimar cuántas plantas podrían estar infectadas en toda la zona.
	
	\item En un programa de fortalecimiento del sector agrícola, se incorporan \textbf{88 profesionales del área agronómica} (ingenieros agrónomos, técnicos agrícolas y especialistas en riego), los cuales son distribuidos en dos equipos de trabajo: \textbf{Grupo A} y \textbf{Grupo B}.
	
	Se sabe que el \textbf{Grupo A tiene 20 profesionales más que el Grupo B}.
